# Kin — Chrome Extension (Manifest V3 Shell)

This folder contains the **Manifest V3 Chrome Extension Shell** for Kin, showcasing the side panel, active tab monitoring indicator, and direct bridge to the local Kin AI companion.

## How to Load in Google Chrome:

1. Open Google Chrome.
2. In the URL bar, go to: `chrome://extensions`
3. Toggle on **Developer mode** in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select this folder:
   `C:\Users\imran\Downloads\Kin-Family-Safety-Assistant\Kin-Family-Safety-Assistant\chrome-extension`
6. Click the extension icon in your Chrome toolbar or pin it to open the **Kin Guardian Side Panel**!
